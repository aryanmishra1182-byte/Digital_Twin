## 2. Experimental Dataset Semantics & Partitioning
- **Primary Telemetry:** Synthetic dynamic simulation of IEEE-specified 3 kW, 415 V, 50 Hz, 4-pole three-phase induction motor ($s = 0.04$, nominal speed 1440 RPM).
- **Run vs. Window Partitioning Semantics:**
  - Strict zero-leakage run-level splitting (partitioning performed on unique `run_id` lifecycles, **never** random window slicing).
  - Total runs: **208 runs** (6 windows per run = 1,248 total 1-second windows).
  - **Training Split:** 104 runs (624 windows; 48 Healthy, 576 Faulty across 4 loads: 25%, 50%, 75%, 100%).
  - **Validation Split:** 52 runs (312 windows; 24 Healthy, 288 Faulty).
  - **Held-Out Test Split:** 52 runs (312 windows; 24 Healthy, 288 Faulty).
- **Remaining Useful Life (RUL) Trajectories:**
  - 12 total progressive degradation runs (8 training runs, 4 held-out test runs).
  - Held-out test runs: `RUL_BRO_03`, `RUL_STA_03`, `RUL_BEA_03`, `RUL_AIR_03` (96 sequences each = 384 test sequences).
